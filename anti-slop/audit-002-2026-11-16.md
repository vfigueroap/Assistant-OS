## Hallazgos corregidos

1. **Alta, R-26/R-35:** la copia local no tenía configurado el proyecto existente. Se verificaron Supabase Assistant-OS y la configuración pública de su despliegue Vercel, y se creó `.env` con URL y clave publicable, sin credenciales administrativas.
2. **Alta, R-26:** el adaptador intentaba borrar transferencias expiradas sin permiso en la base real. Se aplicó solo `gym_expired_snapshot_cleanup`, sin reemplazar RPC ni migraciones anteriores. La prueba real con rollback confirmó dueño/expiración, denegación a terceros y ausencia de filas sintéticas al terminar.
3. **Alta, R-27:** el orden de eventos de autenticación podía ocultar el rechazo de una cuenta sin propiedad. Se valida al propietario antes de mostrar registros; el callback de Auth se verifica fuera de su lock y el formulario evita una doble desconexión. El caso pasó seis ejecuciones de regresión desde `/login` y `/`.
4. **Media, C-2/C-4:** usar la versión compilada dependía de Vite. `npm start` usa ahora un servidor Node compilado, con rutas web, API y gimnasio en el mismo puerto de loopback. `Iniciar.cmd` abre esa copia y reutiliza la instancia existente.
5. **Alta, C-4:** configurar la cuenta hacía menos accesibles los registros locales. El enlace **Usar registros de este navegador** permite abrirlos y volver a la cuenta sin mezclarlos ni migrarlos.
6. **Media, R-37/R-39:** se retiró del producto el aviso interno de borrador. DESIGN.md documenta la dirección de continuidad con identidad ya existente; no se crearon assets ni se afirma una aprobación visual del usuario.

## Límites comprobados

El entorno de ejecución bloquea conexiones de red del navegador y del proceso Node hacia servicios externos. Por eso no se inició sesión web con una cuenta real ni se acreditó sincronización entre dispositivos. La base y los permisos sí se comprobaron a través del conector autorizado; la API publicada respondió mediante el conector Vercel.

La extracción de TXT, DOCX, PPTX y XLSX pasó con el runtime Python instalado; el servicio HTTP requiere FastAPI, uvicorn y multipart exactos ausentes. PyPI está bloqueado con WinError 10013 y Tesseract no está instalado. Se retiró el venv incompleto creado durante el diagnóstico. No se activaron Docker, OCR, correo, Telegram, Google, Garmin ni inferencia externa. No se crearon cuentas, no se cambiaron contraseñas y no se emitieron tokens de usuario.

El límite remoto de gimnasio incluye JSONB y sus metadatos; no se reemplazó su función avanzada por la versión local. La respuesta 413 trata esa diferencia sin perder rutinas.
